ResponseStar

ResponseStar is a full-stack survey analytics application developed with MeteorJS, React, and MongoDB. The platform integrates with LimeSurvey and SurveyMonkey, allowing users to effectively categorize and tag free-text responses. Furthermore, it provides detailed analytical insights into survey answers and tagging patterns. As this is a proprietary system, the source code is unavailable.

Ct-Wrap

Ct-wrap is a serverless wrapper application designed to improve the readability and accessibility of data from clinicaltrials.gov. Built with NodeJS and React, it interfaces directly with the ClinicalTrials API to present complex trial information in a highly user-friendly format. The application also supports exporting trial data in various formats for further analysis.

Audiomata

Audiomata is an audio management tool developed for the Unity game engine. It enhances audio flexibility by enabling users to tag audio clips and perform advanced searches based on those tags. Additionally, it leverages command and factory design patterns to provide comprehensive control over audio components, such as allowing gradual fade-in transitions for reverb effects.

m-strat

m-strat is an ongoing project that started as a final project for my Master's in AI. It is a AuotML Directed Acyclic Graph Framework which allows is serves as a tool for ML developers to create scriptable blueprints as nodes within a workflow in order to produce highly customisable and data-agnostic processing. By using this system with Data-oriented design principles, (once the project is complete) it is hoped that it will become easier to create and rapidly protoype ML models allowing for quick experimentation and altering of model stack components rapidly.
